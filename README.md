# Puzzle Game

Unity 6000.5.10f1.

## Setup

1. Clone o repositório e adicione a pasta do projeto no Unity Hub.
2. Abra o projeto com Unity 6000.5.10f1.
3. Abra `Assets/Scenes/Game.unity`.
4. Pressione Play.

## Imagens

1. Adicione arquivos em `Assets/Resources/PuzzleImages/`.
2. Abra `Assets/Settings/PuzzleConfig.asset`.
3. Use **Rescan Folder** se a lista não tiver sido atualizada automaticamente.

## Validação

No Editor, execute `Puzzle > Validate Procedural Cuts`.
